# Exploratory Data Analysis (EDA)
Welcome to Exploratory Data Analysis (EDA), the stage where we slow down and get to know our data before building any models. EDA is all about asking simple questions and assessing the quality of our data. By exploring how the data is distributed and how variables relate to one another, we are able to build an intuition that helps guide modelling decision. Getting this right will save you time, prevent subtle mistakes, and often lead to much better models down the track.

<hr class="thick">

## What is Exploratory Data Analysis?
EDA is the process of getting to know a dataset before building any models. It involves using simple statistics and visualisations to understand how the data is structured, how variables relate to one another, and where potential issues might lie. The goal isn’t to model yet, but to build intuition, so that later decisions are informed rather than assumptions.
