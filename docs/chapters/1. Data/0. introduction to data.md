# Introduction to Data
Welcome to data. In this context, *data* refers to the collection of observations or measurements that we use to train, test, and validate our models. While algorithms often get the spotlight, data is arguably the most important part of everything we do in AI. The performance of any model is heavily influenced by both the quality and quantity of the data it learns from. This section of the notes is designed to help you build intuition when working with data. 

<hr class="thick">

## Common Terminology
Before we go any further, let’s quickly define a few terms that will appear constantly throughout these notes.

!!! quote "Observations"

    Observations are the individual data points, examples, or records used to train, test, or evaluate a model.

    As an example, consider the following table:

    | Student ID | First Name | Last Name | GPA |
    | :----------: | :----------: | :---------: | :------: |
    | 12345678 | Adam | Johnson | 4.8 |
    | 23456781 | Ben | Stiller | 6.4 |
    | 34567812 | Clair | Miller | 5.3 |

    where an observation from this table would be:

    | Student ID | First Name | Last Name | GPA |
    | :----------: | :----------: | :---------: | :------: |
    | 12345678 | Adam | Johnson | 4.8 |

!!! quote "Features"

    A feature is an individual measurable property or characteristic of the observations. As an example, the features of the table:
    
    | Student ID | First Name | Last Name | GPA |
    | :----------: | :----------: | :---------: | :------: |
    | 12345678 | Adam | Johnson | 4.8 |
    | 23456781 | Ben | Stiller | 6.4 |
    | 34567812 | Clair | Miller | 5.3 |
    
    would be "Student ID", "First Name", "Last Name" and "GPA".

!!! quote "Labels"

    The label, also known as the "dependent variable", "response variable", "output variable", or "target" is the specific outcome or metric that a model is trained to predict or classify based on a given set of features.

!!! quote "Categorical and Numerical Data"

    Features can be described as either numerical or categorical. 
    
    Numerical data represents quantities that can be measured, such as height, temperature, or time.
    
    Categorical data represents groupings, such as brand, country, or gender.  

    !!! warning "Note"
    
        It is common practice to label binary results as "1" or "0". These recordings represent categorical data and should not be treated as numerical data. 
        
        Treating categorical data as numerical data will likely invalidate your results.
