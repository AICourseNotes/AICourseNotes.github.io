# Vectors
Vectors are the basic building blocks of linear algebra and machine learning. They are how we represent data points, directions, and features numerically. Before working with distances, models, or transformations, we need to be comfortable thinking in terms of vectors.



## Intuition


*Suppose you are describing a student using three pieces of information: height (cm), hours studied per week, and exam score.*

One student might be described as:

\[
(170,\;15,\;82)
\]

Each number alone tells you something, but together they describe a single object. This ordered collection of numbers is called a **vector**.

In machine learning:
- Each data point is a vector  
- Each feature corresponds to one component of the vector  
- Similarity and distance are computed between vectors  

This is exactly what happens in $k$-Nearest Neighbours, where we compare one vector to others to decide how similar they are.



## What Is a Vector?


A **vector** is an ordered list of numbers.

Examples:
- A 2D vector: \((x, y)\)
- A 3D vector: \((x, y, z)\)
- A vector with $n$ features: \((x_1, x_2, \dots, x_n)\)

Key ideas:
- A **scalar** is a single number  
- A **vector** is multiple numbers grouped together  
- The **dimension** of a vector is the number of components it has  

A vector can be interpreted in two common ways:
- As a **point in space** (a data point)
- As a **direction and magnitude** (a displacement)

In machine learning, we almost always think of vectors as **data points**.



## Vector Notation


Vectors can be written in several equivalent ways:

- Parentheses: \((x, y, z)\)
- Column vectors:
\[
\begin{bmatrix}
x \\
y \\
z
\end{bmatrix}
\]

Throughout these notes:
- We treat vectors as **column vectors**
- We use parentheses when writing vectors inline

This convention matters later when we multiply vectors by matrices.

Every supervised learning algorithm starts with vectors.



## Theory Problems

!!! question "Theory Question 1"

    What does the dimension of a vector represent?

??? note "Solution"

    The dimension of a vector is the number of components (features) it contains.



!!! question "Theory Question 2"

    In machine learning, what does a single vector usually represent?

??? note "Solution"

    A single data point or observation.



## Concluding Notes
Vectors are the language used to describe data in machine learning. Once vectors are understood, matrices, transformations, and models become natural extensions rather than new ideas.
